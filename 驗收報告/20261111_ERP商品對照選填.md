# 品項名稱對照：公司 ERP 商品選填

使用者要求「公司 ERP 商品」先設為選填，允許先保存供應商專業品名，之後補上 ERP 對應商品。

- 新增與編輯時不必選 ERP 商品，未選商品以待確認保存，清單顯示「尚未指定 ERP 商品」。補選後可以確認；清除已選商品會回到待確認。
- Excel 的 ERP 商品編號欄及其值均可省略；有填編號時仍核對既有商品，不新增另一套主檔。未填編號的 ERP 商品名稱需留白，以免忽略誤填資料。
- 新 migration `20261111051652_item_alias_optional_erp_item.sql` 只放寬既有對照表的商品 FK 欄位為 nullable，新增未對照重複檢查索引與已確認需有商品的 constraint，調整原有讀寫 RPC。保留函式 ACL、RLS、FK、版本與異動紀錄。
- 未指定 ERP 商品的資料僅在對照管理顯示，不參與商品配對或交易選取，不影響庫存、成本與歷史交易。

驗證：542 項既有回歸測試通過；實際 migration 的 PGlite SQL 驗證共 5 組，涵蓋選填儲存／查詢／匯入、補選、清除、重複、權限、版本、異動歷程與整批回滾。隔離測試站實際使用瀏覽器操作儲存、查詢、編輯、Excel 匯入及桌面／手機版顯示，商品主檔與交易筆數維持原狀。測試資料已停用，正式容器未受測試影響。

本檔為開發驗收快照；正式發布與 main 合併狀態以部署主機的本次發布紀錄為準。
