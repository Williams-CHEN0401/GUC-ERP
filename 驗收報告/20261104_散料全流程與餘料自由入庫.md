## 已確認的規則

1. 只有弱電線材、電線&電纜類提供新交易的「散料(米)」，不再綁定包裝長度或期初散料。其他類別的既有米數紀錄保留，不能因開啟表單而變成包裝數。
2. 修改現有貨品的單位／每單位米數，保留現有庫存數量與舊單，設定供目前及新交易使用；不自動換算數量，不把舊單未知長度填成305米。
3. 依使用者最後指示，餘料入庫獨立於取貨：不要求先登錄取貨、不限制可退上限，不因原包裝規格變動或後續取貨而阻擋修改／取消／刪單。數量有誤可人工盤點校正。
4. 權限、可存取客戶／工作內容、有效品項、有效數字、版本與重試識別仍沿用原模型；本次沒有另建Auth、客戶、貨品或RBAC。

## 各網站與流程

| 範圍 | 結果 |
|---|---|
| ERP進貨、取貨及工作日誌取貨 | 共用單位資格，不需先填每箱長度；原米數、價格及庫存規則維持 |
| ERP案場餘料入庫 | 修正被長度鎖住的選項；既有明細可改單位／品項，分段米數選填，不設領料量上限 |
| ERP供應商退貨 | 補上米數與小數計價，箱與米分帳；保持供應商來源、價格權限及可用庫存檢查 |
| ERP盤點校正 | 可選原單位或散料米數，零規格也可校正，儲存後核對實際庫存 |
| ERP貨品單位設定 | C005既有CAT-6可補設305米及修改單位；舊交易與庫存數量不變 |
| ERP／會計工作報表 | 採交易快照或原單位，依貨品及實際單位分組，不混加箱與米、不誤套舊箱價為米價 |
| 案場承攬網站 | 查核72個相關程式檔；無獨立庫存米數選擇器，沿用原設備／電話功能 |
| 報價／會計網站 | 查核68個相關程式檔；報價單位是自由文字，會計用料讀取共用報表，未發現另一個鎖住米數的庫存表單 |

修改／刪除餘料單仍以新增差額紀錄記帳，不修改舊庫存帳。更改計量模式會分別回沖舊模式及增加新模式；同一明細／版本按模式保持唯一。回沖可產生負庫存的例外只限合法餘料來源，其他來源的非負庫存條件保留。已實測負8米校正為7.25米、負1包校正為4包。
