## 統計呈現

原本人員長條圖使用各施工人員的 `constructionDays`，顯示累計施工天數。本次以每日施工人數呈現：橫軸為工作日期，縱軸與數值單位為「人」，刻度只顯示整數。

沿用已授權報表 API 的 `dailyRows.dailyHeadcount`。後端已計算同一人同日去重，並加入當日最高代工人數；前端只將同日期重複出現在多筆日誌中的統計值呈現一次，不加總重複日誌，也不把施工天數換標成「人」。

總覽與施工人員頁籤使用相同圖表。保留「施工人員明細」的施工天數、日誌筆數及首次／最近施工日期，沒有變更工資或施工投入的計算。無人數資料時不從天數推估，明確顯示沒有每日人數紀錄；有效的 0 人仍可顯示。
