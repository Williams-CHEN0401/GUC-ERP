## 資料與權限決策

- 客戶、案場、合約、負責人由既有 project ID 關聯，不複製主檔。
- project_type=construction 且 construction_category in (small_purchase,tender) 才能新建規劃。
- 負責人使用 project_workers.is_assignee 的正式 user ID；需工作內容 VIEW / UPDATE，管理員保留既有能力。
- 日誌沿用工作日誌 VIEW / CREATE / UPDATE / DELETE。施工指派只授予該規劃，不擴大成整個專案授權。
- 施工人員只能修改／刪除自己的規劃日誌；管理員沿用既有管理能力。私人資料限制優先，不因指派而放寬。
- 多人指派存 relation；移除人員只撤銷後續新增權限，歷史日誌保留。
- 有日誌（含封存紀錄）的規劃禁止刪除，提示改為取消；無日誌可封存刪除，保留稽核。
- 首頁從規劃指派 relation 產生顯示項目，不另寫 work_assignments，不重複建立任務。日誌不自動完成規劃。
