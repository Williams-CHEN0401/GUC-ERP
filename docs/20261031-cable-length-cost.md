# 線材預設長度與歷史成本保護

本次修改範圍為 prompt1031-2 需求 3。基底為整合分支的 `04c3433e5a9f9bd17da402fb2945cd251a5fb714`；未部署、未推送 GitHub，未寫入正式資料。

## 資料與操作

- 沿用 `inventory_items.meters_per_unit`。新增品項及原編輯表單提供「預設長度（公尺）」；線材與電線&電纜類可設定，未填不會自動變成 305。
- 進貨仍為原箱／捲數量。米數取貨不足時，同一資料庫交易鎖定品項，透過既有不可覆寫 `stock_adjustments` 帳本拆足量包裝；一筆扣包裝、一筆加米數。餘料退回仍經既有 `save_site_return_v1` 加回米數。
- 取消米數領用只歸還散米，不假裝將拆開的箱子重新封箱。原包裝取貨、非線材及進貨計稅流程沿用既有規則。
- 進貨、領用、退料與人工參考價新增換算率／包裝單位快照。編輯原單日期、備註或米數，不重新讀取目前品項長度來改寫歷史。

## 成本基準

沿用人工參考價格優先、最近已確認送達進貨的未稅價格口徑。含稅進貨依原規則先換算未稅，再除以該筆進貨的包裝長度。領料記錄每米參考成本快照；退料按該案尚未退回的數量與成本加權沖回，避免不同單價反覆全退後留下負成本。修改退料數量或轉至其他工作內容時，排除該單原數量重新計價；只改日期備註保留原價。人工參考價格的明確修改仍可覆寫該案參考成本，並保存當次包裝換算率。

每筆成本快照保存來源進貨 ID。新增領料只採操作者可看的來源；會計報表再依當下讀取者檢查來源權限。若來源不可見或已刪除，改用該讀取者可看的既有參考來源，沒有來源則列為未定價。公開工作內容的數量仍可顯示，不會因內部成本來源為私人資料而整筆隱藏。原單筆寫入 API、ERP 報表及退料清單均不回傳內部成本與來源欄位。

這是既有材料參考成本的快照保護，不是新增 FIFO、批次存貨估價或財務結帳模型。原進貨整單折扣、稅額、應付金額均不重算。只有最後金額四捨五入至兩位小數；每米成本採 PostgreSQL numeric 保留精度。

## 歷史資料與限制

- 已設定長度的舊資料，只固定 migration 當時既有計算基準，標記 `cable_snapshot_source='migration_baseline'`；不宣稱還原當年未記錄的規格。新交易標記 `recorded`。
- 舊資料從未設定長度時保留 NULL，不推測為 305。已有交易的這類貨品需建立已設定長度的新貨品供後續米數交易使用，避免將歷史箱數突然當成米數。
- 尚有原規格整包庫存或待確認進貨時，不允許直接改預設長度。包裝庫存為零後可以修改；既有散米、歷史用量及參考成本不變。
- 改規格後，不能直接修改／刪除舊規格的包裝交易來回沖成現行規格；可讀取及改日期備註。這項檢查位於資料庫，以防只透過 API 修改而繞過 UI。
- ERP 非會計報表及餘料入庫 API 不會包含新增成本快照欄位。沒有更動 Auth、動態 RBAC 或 RLS。
