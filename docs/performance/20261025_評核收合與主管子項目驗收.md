# 評核收合與主管子項目驗收

## 功能

- 每個評核項目預設收起，沿用施工規劃明細的加減號與摘要樣式；摘要顯示職務、項目、評級及權重。展開可評分，收合保留尚未保存的輸入。
- 「現場帶班／主管」顯示名稱統一為「主管職務」。管理員可新增主管考核子項目，其他三職務各維持七項；每職務總權重仍須 100%。
- 管理員可在「考核設定 → 既有權重版本 → 修改項目／建立新版」修改名稱、說明及權重。新增內容採新版本保存。
- 草稿中的「修改評核項目」可建立新版並套用，或套用既有版本。需填原因並勾選清除舊評級確認；保留配比、佐證及改善行動，舊評級留在操作稽核。
- 已送出／核定／發布不接受換版；已發布的新修訂承接原有效版本。新月份可選新版，其他已建立評核不受影響。
