## 實作

清單資料列依既有角色輸出編輯目標與焦點屬性，事件直接開啟既有表單；移除透過「修改」按鈕 click 間接編輯的依賴。開啟時再次檢查角色，專案保留負責人清單的非同步載入。操作按鈕、連結、輸入欄位及選單不觸發資料列的觸控開啟。
